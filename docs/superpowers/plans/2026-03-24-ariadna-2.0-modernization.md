# Ariadna 2.0 Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Modernize Ariadna to align with Claude 4.6 platform capabilities — Memory Tool patterns, Agent Skills, and lean goal-oriented prompts — using a vertical slice strategy on the plan/execute/verify loop.

**Architecture:** Clean break (2.0). StateManager rewrites for Memory Tool directory patterns. Rails guides restructure into SKILL.md packages with progressive disclosure. Agents shrink from ~600-line protocols to ~60-line goal documents. Init returns paths instead of contents. Four phases: Foundation (Ruby), Content (Skills/agents/workflows), Wiring (commands/installer), Rollout (remaining components).

**Tech Stack:** Ruby >= 3.1.0, Minitest, Claude Code slash commands, Agent Skills (SKILL.md format)

**Spec:** `docs/superpowers/specs/2026-03-24-ariadna-2.0-modernization-design.md`

Create tests for the new verb-based interface. Each test should set up a temp directory with a `memory/` subdirectory and test the operations:

```ruby
class StateManagerTest < Minitest::Test
  def setup
    @tmpdir = Dir.mktmpdir
    @memory_dir = File.join(@tmpdir, ".ariadna_planning", "memory")
    FileUtils.mkdir_p(@memory_dir)
  end

  def teardown
    FileUtils.rm_rf(@tmpdir)
  end

  # state list — lists memory directory contents
  def test_list_memory_directory
    File.write(File.join(@memory_dir, "progress.md"), "# Progress")
    File.write(File.join(@memory_dir, "decisions.md"), "# Decisions")
    result = dispatch_state(["list"], cwd: @tmpdir)
    assert_includes result, "progress.md"
    assert_includes result, "decisions.md"
  end

  # state view <path> — reads a memory file
  def test_view_memory_file
    File.write(File.join(@memory_dir, "progress.md"), "Phase 1 of 3")
    result = dispatch_state(["view", "progress.md"], cwd: @tmpdir)
    assert_includes result, "Phase 1 of 3"
  end

  # state create <path> <content> — creates a new memory file
  def test_create_memory_file
    dispatch_state(["create", "blockers.md", "No blockers"], cwd: @tmpdir)
    assert File.exist?(File.join(@memory_dir, "blockers.md"))
    assert_equal "No blockers", File.read(File.join(@memory_dir, "blockers.md"))
  end

  def test_create_fails_if_exists
    File.write(File.join(@memory_dir, "progress.md"), "existing")
    assert_raises(SystemExit) { dispatch_state(["create", "progress.md", "new"], cwd: @tmpdir) }
  end

  # state update <path> <old> <new> — str_replace in a memory file
  def test_update_replaces_text
    File.write(File.join(@memory_dir, "progress.md"), "Phase 1 of 3\nStatus: in_progress")
    dispatch_state(["update", "progress.md", "Phase 1 of 3", "Phase 2 of 3"], cwd: @tmpdir)
    content = File.read(File.join(@memory_dir, "progress.md"))
    assert_includes content, "Phase 2 of 3"
    refute_includes content, "Phase 1 of 3"
  end

  # state delete <path> — removes a memory file
  def test_delete_memory_file
    File.write(File.join(@memory_dir, "blockers.md"), "temp")
    dispatch_state(["delete", "blockers.md"], cwd: @tmpdir)
    refute File.exist?(File.join(@memory_dir, "blockers.md"))
  end

  # state insert <path> <line> <text> — inserts text at a specific line
  def test_insert_text_at_line
    File.write(File.join(@memory_dir, "progress.md"), "Line 1\nLine 2\nLine 3\n")
    dispatch_state(["insert", "progress.md", "2", "Inserted line"], cwd: @tmpdir)
    content = File.read(File.join(@memory_dir, "progress.md"))
    lines = content.split("\n")
    assert_equal "Inserted line", lines[1]
    assert_equal "Line 2", lines[2]
  end

  # Convenience wrappers
  def test_add_decision
    File.write(File.join(@memory_dir, "decisions.md"), "# Decisions\n")
    dispatch_state(["add-decision", "Use JWT for auth"], cwd: @tmpdir)
    content = File.read(File.join(@memory_dir, "decisions.md"))
    assert_includes content, "Use JWT for auth"
  end

  def test_record_metric
    File.write(File.join(@memory_dir, "metrics.md"), "# Metrics\n")
    dispatch_state(["record-metric", "--phase", "1", "--duration", "45m", "--tasks", "12"], cwd: @tmpdir)
    content = File.read(File.join(@memory_dir, "metrics.md"))
    assert_includes content, "Phase 1"
  end
end
```
